# Bharat Build Mart - Static Website

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- No database
- No backend
- No API

## Pages
- index.html
- about.html
- products.html
- services.html
- gallery.html
- contact.html

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important
The phone/WhatsApp value in the sample links is based on the short number visible in the supplied advertisement. Replace it with the business's complete real phone/WhatsApp number before publishing.

The Google Maps link is a search link. Verify the exact business pin/address before publishing.

The supplied advertisement image is used as the main visual. Add real showroom/product images to the `images` folder and update `gallery.html` as needed.
